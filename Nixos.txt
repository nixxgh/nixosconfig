# NixOS Roadmap

## Completed
- [x] NixOS (Base system on nixos-unstable, LUKS, systemd-boot)
- [x] Git (Configured in Home Manager with GitHub identity)
- [x] Gh (GitHub CLI managed via Home Manager)
- [x] Neovim (Basic setup with clipboard integration)
- [x] Niri (Wayland tiling compositor + keybindings)
- [x] Noctalia (Shell / bar + auto-export on shutdown hook)
- [x] Home Manager (Dendritic integration in modules/home/nixx.nix)
- [x] Greeter (SDDM display manager)
- [x] Maintenance & GC (Automatic weekly cleanup, store deduplication, nixclean and safe update aliases)
- [x] ZSH Shell (Default shell, autosuggestions, syntax highlighting, Starship prompt)
- [x] Tmux (Terminal multiplexer with vim navigation & mouse support)
- [x] Yazi (Terminal file manager + rich preview plugins & shell integration)
- [x] Fastfetch (System information display + ff alias)
- [x] Tailscale (Mesh VPN daemon & firewall routing)
- [x] Sunshine (Desktop/game streaming host for Moonlight client on phone)
- [x] SSH (OpenSSH daemon for remote access via Termius & Tailscale)
- [x] Zen Browser (Managed via Home Manager using zen-browser-flake)
- [x] Niri Defaults & Aesthetics (Full-width 100% maximized columns, subtle grey focus ring, Mod+HJKL navigation)

- [x] Remote LUKS Disk Unlock (TPM 2.0 Auto-Unlock): Enrolled PCR registers 0+2 for root & swap via systemd-cryptenroll for autonomous boot without password prompts
- [x] Remote Autologin: Setup 'autologin' / 'autounlock' command via SSH (with NOPASSWD sudo) to seamlessly log into SDDM, initialize Niri, and unlock the physical desktop session cleanly
- [x] Wake-on-LAN (Wired Ethernet): Declarative systemd link, NetworkManager connection config, dispatcher scripts, udev rules, and boot service for eno1 interface
